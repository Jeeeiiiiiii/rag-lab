What ran

Attribution

Citations must be labels the answerer was handed; anything else is dropped. Held copy never reaches it. Labels are file#chunk, shown without .md.

    Intake

    The corpus is corpus/*.md. Each chunk's id is a hash of its source, position, flags and text, so re-ingesting embeds only what changed. Edit a file, then re-ingest and watch the count.

    Accuracy audit

    The golden set is 28 questions with a known source and phrase. The audit runs python -m rag_lab eval --gate 0.9, the command CI gates on: hit@1 is "right copy filed first", hit@5 "filed anywhere in the top 5", MRR the average of 1 / rank.

    Every number on this page comes from the running lab: the API's /search, /ask, /ingest, /healthz and /metrics, chunk text from Qdrant, and the eval command. Nothing is precomputed.
